# AI 审核过滤规则

AI 审核时，先按这里去掉不值得报的意见。改这个文件属于高风险，由用户合并。

## 不报

- 格式、import 顺序这类 gofmt 和 golangci-lint 已经管着的事。
- 命名、注释措辞、文档润色等个人偏好；会造成误解或与事实不符的除外。
- 没有指出具体缺陷的"可以考虑……"式建议。
- 和本 PR 无关的既有问题。只有确实影响本 PR 正确性时才报，并标 [既有问题]。

## 必须报

- **正确性**：逻辑错误、并发和资源泄漏、漏掉的错误处理、边界条件。
- **越过 [AGENTS.md](../../AGENTS.md) 的边界**：在 sing-box 之外裁决 DNS 或路由、在 CLI 或 App 里放业务逻辑、新增没批准的依赖、打补丁。
- **测试与证据**：行为改了却没有对应的测试；PR 里的证据和 diff 对不上。
- **安全**：权限边界、凭据、注入、供应链。
