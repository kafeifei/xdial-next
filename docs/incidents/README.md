# 事故记录

线上问题，包括用户日常用 Debug 时发现的，都在这里留一份记录。规则见[项目循环](../agent/loop.md#问题回流)。

每份记录一个文件，文件名用 `YYYY-MM-DD-简短英文描述.md`，写清五件事：

1. **现场**：什么时间、什么版本、看到了什么，附上日志或输出里关键的几行。
2. **原因**：怎么查到的；引入问题的 PR（查不到就写明）；哪些是确认的，哪些是推断。
3. **修复**：对应的 PR。
4. **验证范围**：修复后验证了什么，还有什么没验证。
5. **回流**：加了哪个回归测试；哪条审核评测用例（问题描述，加上引入它的 PR）；能归纳成一类问题的，加了哪道门禁，什么情况下可以退役。
